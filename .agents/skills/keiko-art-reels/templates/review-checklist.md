# 最終確認表

必要な項目だけ使う。未確認を確認済みにしない。

- [ ] 台本の全行を読み、秒数と静止画の対応が合っている。
- [ ] セリフ、結論、CTAを指定外で変えていない。
- [ ] 本人作品の写真・色・細部を描き直していない。
- [ ] 本人作と誤解される架空作品・実績を追加していない。
- [ ] 平面、切り抜き、貼る、重ねるの工程を混同していない。
- [ ] 腕・手首・指・道具・PCの表裏が自然につながっている。
- [ ] 表情・視線・構図が場面に合い、同じ正面構図だけになっていない。
- [ ] 表紙の主役語と補助文の差が見える。
- [ ] 強調語の色、太さ、位置が明瞭で、CTAやUIに埋もれない。
- [ ] 指定された文字・図のアニメーションを実装し確認した。
- [ ] 静止画確認を終えてから動画化した。
- [ ] 読み、抑揚、語尾、区切りについて本人の確認が取れている。
- [ ] 声を急に速めず、長い無音も整理した。
- [ ] 音量・ピーク・全編再生を確認した。
- [ ] 第0秒の表紙と最後のCTAがファイルに入っている。
- [ ] 正しい最終版の軽いMP4をリンクで渡した。
- [ ] PCへのダウンロードと再生が確認できた。
- [ ] 了承された残存点と完成リンクを記録した。
